# Animal Personality Test

This interactive quiz presents personality-test content from Michigan State University. The original worksheet and its animal-style descriptions are credited to Michigan State University and the sources identified in the quiz.

Codex was used to create the interactive interface for this quiz.

## Run locally

Open `index.html` in a web browser.

## Source material

- [Michigan State University: Situated Spartan Handouts (PDF)](https://communityengagedlearning.msu.edu/upload/Situated%20Spartan%20Handouts.pdf)
- [Upworthy animal personality test](https://www.upworthy.com/fun-personality-test-how-you-love-as-different-animals-ex1/)

## How it works

Rank the four words in each of ten rows from most like you to least like you. The quiz assigns 4, 3, 2, and 1 points per row and totals the L, O, G, and B columns. The highest score shows the matching Lion, Otter, Golden Retriever, or Beaver profile. Ties show each top-scoring profile.

This is a self-reflection activity, not a clinical or validated personality assessment.
