# Animal Personality Test

A lightweight, interactive version of the four-column animal personality worksheet.

## Play

Open [index.html](index.html) in a browser, or enable GitHub Pages for this repository to host it as a website.

## How it works

Rank the four words in each of ten rows from most like you to least like you. The app assigns 4, 3, 2, and 1 points per row and totals the L, O, G, and B columns. The highest score shows the matching Lion, Otter, Golden Retriever, or Beaver profile; ties show each top profile.

The test is a fun self-reflection exercise, not a clinical or validated assessment.
